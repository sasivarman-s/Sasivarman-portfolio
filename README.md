## 🌟 Overview

This is my personal **portfolio website**, built entirely with **HTML** and **Tailwind CSS**. It's a multi-page site that introduces me as a web developer and 2nd-year CSE student, highlights the projects I've built (Mark Calculator, ERP Simulator, Book Catalogue, Tourism, and Food Store websites), and gives visitors easy access to my resume, tools, and a way to reach out.

> 🔥 **[Click here to view the live website](https://sasivarman-portfolio.vercel.app/)**

---

## ✨ Features

- 🏠 **Home Page** — A crisp intro: *"Hi, I'm Sasivarman — web developer and designer, 2nd Year CSE Student"*
- 🙋 **About Page** — My background, academic journey at Meenakshi Sundararajan Engineering College, technical interests (AI, MERN stack), and achievements
- 💼 **Projects Page** — A showcase grid of my work, each with a live demo link and GitHub link
- 📄 **Resume Page** — Quick access to my resume for recruiters and collaborators
- 🛠️ **Tools Page** — A dedicated section for tools/utilities I've built or use
- ❓ **AMA Page** — An "Ask Me Anything" section for visitors to learn more about me
- 🔗 **Social Links** — Direct links to my GitHub, Instagram, and X (Twitter)
- 📱 **Fully Responsive Design** — Built with Tailwind CSS utility classes for a seamless experience across all devices

## 📂 Getting Started (Run Locally)

1. **Clone the repository**
   ```bash
   git clone https://github.com/sasivarman-s/portfolio-revamp.git
   ```
2. **Navigate into the project folder**
   ```bash
   cd portfolio-revamp
   ```
3. **Open `index.html`** in your browser — that's it! No build step required.

   *(If you're using the Tailwind CLI/build process instead of the CDN, run `npm install` and your Tailwind build command as configured in the project.)*
